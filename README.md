## Student Directory Viewer

## Project Description
The Student Directory Viewer is a mobile application built using React Native. It displays student information, profile pictures, year levels, and flag buttons.

## Components Used
- View
- Text
- Image
- ScrollView
- TextInput
- Pressable

## Features
- Displays five students.
- Shows student names and year levels.
- Displays student profile pictures.
- Allows users to flag and unflag students.
- Allows users to search students by name.
- Uses React state and props.

## Component Structure

### StudentDirectory
The parent component that manages the student list and search query using useState.

### StudentCard
A functional component that receives student information through props and displays each student's details.

## TextInput Experiment
When the value and onChangeText properties are removed, the search input accepts text but does not filter the student list.

When these properties are restored, the search functionality works correctly.

## How to Run

1. Install dependencies:

   npm install

2. Start the application:

   npx expo start

3. Scan the QR code using Expo Go.

## Conclusion
This project demonstrates the use of React Native core components, props, state, and event handling in building a Student Directory Viewer.
